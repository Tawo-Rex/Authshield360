# AuthShield 360

## EduSecure Portal

AuthShield 360 is a security-focused authentication and authorization system developed for the TechWiz7 Ethical Cyber Horizon competition.

The project demonstrates how a fictional educational portal can protect student, teacher, and administrator accounts using layered identity security controls.

---

## Project Objectives

AuthShield 360 demonstrates:

- Secure password authentication
- Password hashing
- Multi-factor authentication (MFA)
- Time-based One-Time Password (TOTP)
- Email step-up verification
- Role-Based Access Control (RBAC)
- Failed-login protection and account lockout
- Secure session management
- Session timeout and logout invalidation
- Authentication and authorization logging
- Controlled ethical security testing
